# 截图说明

请将以下截图放置在此目录中：

1. **desktop.png** - 桌面端主界面截图（推荐尺寸：1920x1080 或 1440x900）
   - 显示聊天/生图界面
   - 包含参数面板
   - 展示生成的图片

2. **mobile.png** - 移动端界面截图（推荐尺寸：375x812 或 390x844）
   - 展示手机端的响应式布局
   - 显示触控优化的界面

3. **library.png** - 灵感库界面截图
   - 展示提示词模板库
   - 显示案例浏览功能

4. **gallery.png** - 画廊视图截图
   - 展示瀑布流图片展示
   - 显示已生成图片的管理界面

## 截图建议

- 使用实际的界面进行截图
- 确保图片清晰，DPI 至少 72
- 避免包含敏感信息（API Key 等）
- 推荐使用 PNG 格式保持清晰度
